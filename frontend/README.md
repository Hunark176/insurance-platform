# Insurance Platform Frontend

React- und TypeScript-Frontend für die Insurance Platform.

## Entwicklung

Aus dem Repository-Stamm starten:

```powershell
npm run dev
```

Oder direkt in diesem Verzeichnis:

```powershell
npm run dev
```

Das Vite-Development-Setup leitet API-Aufrufe unter `/api` an das Spring-Boot-
Backend auf `http://localhost:8080` weiter.
